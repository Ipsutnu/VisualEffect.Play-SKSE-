## Source Availability

The source code of this project is publicly available for transparency,
inspection, learning, and reference.

**This does not mean that the project is open source.**

You may read and inspect the source code.

You may NOT:
- modify the source code;
- create forks;
- create derivative works;
- redistribute the source code;
- redistribute modified versions;
- publish modified versions;
- use portions of the source code in other projects.

Only the original author may modify and publish the official project.
